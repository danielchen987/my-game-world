# My Game World 🎮

一個給小朋友玩的趣味遊戲樂園。第一款遊戲是「貪食蛇大冒險」。

## 目前功能

- 🐍 貪食蛇：吃到蘋果累積分數
- ⚡ 可調整蛇蛇速度：慢慢走、普通、快速、超級快
- 🗺️ 可調整活動範圍：12×12、16×16、20×20、24×24
- 🍎 可設定蘋果消失時間：0 秒（預設，永不消失）、5、10、15 或 30 秒
- ⌨️ 支援方向鍵與 WASD 鍵盤操作
- 📱 支援手機和平板的觸控方向按鈕與滑動操作
- ⏸️ 暫停、繼續及重新開始
- 🏆 使用瀏覽器 LocalStorage 記錄最高分
- 🌈 兒童友善、響應式介面

## 本機執行

直接用瀏覽器開啟根目錄的 `index.html` 即可，無需安裝套件或啟動伺服器。

## 部署到 GitHub Pages

1. 開啟 repository 的 **Settings → Pages**。
2. 在 **Build and deployment** 中選擇 **Deploy from a branch**。
3. 選擇 `main` 分支及 `/(root)` 資料夾，按 **Save**。
4. 等待部署完成後，於 Pages 設定頁面按 **Visit site**。

> 網站發佈後會公開在網路上。最高分只儲存在玩家目前使用的瀏覽器中，不會上傳至伺服器。
